    Author or update a DDD¶

    1. Start with DDD source formats to understand the domain, ontology, and service-interface components.
    2. Choose Domain XML or DDD JSON.
    3. Look up domain declarations and plan items to define dialogue behavior.
    4. Define vocabulary in the ontology and application operations in the Service Interface.

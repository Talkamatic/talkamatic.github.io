    Service Interface targets¶

    Every Service Interface operation has a <target> describing where the operation is handled.

    <target><http endpoint="https://service.example/book-room"/></target>

    Supported targets:

    Target Supported operations Purpose
    <http endpoint="…"/> Actions, queries, validators Calls the configured HTTP endpoint.
    <frontend/> Actions Delegates the action to the application-facing side.

    Queries and validators require HTTP targets. The schema contains an entity_recognizer declaration, but the Tala Service Interface model does not load it as a supported operation.

    See Actions, Queries, and Validators.
